🚗DriveAware Detection System

A real-time driver monitoring system that watches for drowsiness and dangerous emotional states through a webcam feed, triggering audio alerts before either becomes a safety risk.

📅 October 2025 🧱 Python · C · OpenCV · MediaPipe · DeepFace
View on GitHub All Projects
🤝 Built in collaboration with Nick McComb — the repository is hosted under his GitHub account, linked above.

Overview

DriveAware detects two distinct risk signals in real time: physical drowsiness (via eye closure) and dangerous emotional states like anger, fear, or sadness that can impair driving. Rather than a single binary "awake/asleep" check, it combines facial landmark tracking with emotion classification to catch a wider range of unsafe conditions.

How It Works

Drowsiness detection — MediaPipe FaceMesh tracks facial landmarks each frame to compute Eye Aspect Ratio (EAR), a measure of how open or closed the eyes are. When EAR drops below a configurable threshold for longer than a set duration, the system flags a drowsy event.

Emotion analysis — DeepFace classifies frames for anger, fear, sadness, and neutral affect, layered on top of the drowsiness signal to catch emotional-instability risk that eye-tracking alone would miss.

Alerts — OpenCV handles webcam capture and frame processing, while pygame plays audio warnings the moment a threshold is crossed. An ESP32-CAM integration explores pushing the same detection pipeline onto embedded hardware for in-vehicle deployment.

Performance — the detection loop is multithreaded so frame capture, landmark processing, and alerting don't block on each other, keeping latency low enough for real-time use.

Key Features

  • Eye Aspect Ratio–based drowsiness detection with tunable alert threshold and sleep duration
  • Real-time emotion classification for anger, fear, and sadness
  • Live on-screen metrics: blink count, drowsy event tally, head position
  • Audio alert system for immediate driver feedback
  • Multithreaded pipeline optimized for low-latency, real-time response

What I Learned

Real-time computer vision is unforgiving about latency — every extra millisecond in the detection loop shows up as lag a driver would actually notice, which is what pushed the pipeline toward multithreading. Combining two independent signals (eye closure and facial emotion) instead of relying on one also made the system meaningfully more robust to lighting and camera-angle variance than either model alone.
