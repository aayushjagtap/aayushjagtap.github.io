Personal Project

🗂️Branches

A full-stack, Trello-style Kanban board with JWT authentication and persisted drag-and-drop ordering — built end-to-end from a React frontend to a containerized FastAPI backend deployed on AWS.

📅 August 2026 🧱 React · TypeScript · FastAPI · PostgreSQL · Docker · AWS
View on GitHub All Projects

Overview

Branches is a lightweight, Trello/Jira-style Kanban board built to demonstrate end-to-end full-stack engineering: a boards → columns → cards data model, per-user authentication, and a real cloud deployment rather than a localhost-only demo.

Users can create multiple boards, organize work into customizable columns, and reorder cards via drag-and-drop, with every move persisted immediately to the backend so state survives refreshes and devices.

Architecture

Frontend — React + TypeScript, bundled with Vite. Drag-and-drop uses dnd-kit for accessible, dependency-light reordering instead of the native HTML5 drag API.

Backend — FastAPI served by Uvicorn, with SQLAlchemy as the ORM and Pydantic for request/response validation. Auto-generated Swagger docs expose the full REST API.

Auth — JWT access tokens over the OAuth2 password flow, protecting every board/column/card route behind the authenticated user.

Deployment — the React build is served via CloudFront/S3; the FastAPI backend runs containerized on EC2 behind Caddy, which handles automatic TLS certificate issuance and renewal. Persistence was migrated from local SQLite to RDS Postgres, with Alembic managing schema migrations and environment-based configuration replacing every hardcoded credential.

Key Features

  • Multi-board support with per-user isolation via JWT-protected routes
  • Drag-and-drop cards and columns with backend-persisted ordering
  • Inline card creation and renaming without modal dialogs
  • Containerized backend deployment with automatic TLS via Caddy
  • Zero-downtime migration path from SQLite to managed Postgres

What I Learned

Shipping a real AWS deployment surfaced problems a local demo never would — environment-based configuration, credential management, and migrating a schema from SQLite to Postgres without losing data. Wiring Caddy for automatic TLS in front of a containerized API was a good forcing function for treating the backend like a production service instead of a script that happens to run.
