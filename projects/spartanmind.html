🎮SpartanMind Game

A multi-level, Mastermind-inspired desktop game built in C++ with a clean OOP/MVC structure and fully XML-driven level design.

Overview

SpartanMind is a multi-level puzzle game built around Mastermind-style deduction mechanics, developed as an object-oriented software design project. The focus was less on the puzzle itself and more on building a codebase that could scale to new levels and content without touching core game logic.

Architecture

MVC structure — game state and rules (Model) are fully decoupled from the wxWidgets-based UI (View), with a Controller layer routing user input and game events between the two.

XML-driven levels — each level is defined declaratively in XML, describing reusable assets and item placement. New levels can be added without recompiling or touching game logic, since the loader interprets level data at runtime.

Event-driven tiles — tile interactions and feedback are handled through an event system rather than hardcoded per-tile conditionals, keeping the logic scalable as new tile types are introduced.

Key Features

  • XML-based level loading supporting reusable assets and dynamic item placement
  • Event-driven tile mechanics with interactive objects and player feedback
  • Scalable game logic built on OOP/MVC principles
  • 20+ unit tests validating class behavior and gameplay stability across levels

Tech Stack

  • C++
  • wxWidgets
  • XML
  • GitLab

What I Learned

Designing the level format around XML instead of hardcoded level classes made adding content trivial later in the project — a good early lesson in how much a small data-driven design decision can save down the line. Writing 20+ unit tests alongside the game logic also caught regressions early that manual playtesting across multiple levels would have missed.
